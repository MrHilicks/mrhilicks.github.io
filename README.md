## Направления работы

- **Обработка аэросъёмки:** камеральная обработка снимков БПЛА, построение ортофотопланов и подготовка картографических материалов.
- **Геопространственный анализ:** определение площадей и границ объектов, анализ рельефа, высот, уклонов и предварительная оценка объёмов.
- **Computer Vision:** обнаружение, классификация, сегментация и автоматический подсчёт объектов на изображениях.
- **Индивидуальные ML-решения:** разработка специализированных алгоритмов обработки изображений, анализа данных и автоматизации аналитических задач.
