# Владислав Лях / Vladislav Lyakh — сайт-портфолио 1.1

Двуязычный статический сайт: главная EN — `/`, RU — `/ru/`. HTML, CSS, JavaScript; сборка на стандартной библиотеке Python 3.10+. Node.js, npm и сторонние Python-пакеты для запуска не нужны.

Добавлены публичное имя, опыт 5+ лет в ML и Data Science, специализация Computer Vision, описание услуг, Россия/СНГ и удалённый формат. Почта — hilicks@gmail.com; Telegram — @hilicks. Все четыре проекта теперь полноценные демонстрационные кейсы, а не два кейса и два плана.

Агрокейс содержит сравнение RGB-снимка и карты классов одного кадра. Подключены четыре оригинальных PDF-отчёта на русском языке.

Новые карты получены из архива пользователя, а не сгенерированы. Для сайта не выполнялись новые геодезические расчёты, обучение модели или переоценка качества сегментации. Источники и преобразования описаны в `ASSET_SOURCES.md` и `MEDIA_SOURCES.json`.

## Обновление существующего репозитория

Используйте `apply_update.py` из архива обновления. Он проверит структуру проекта, сохранит заменяемые файлы вне репозитория и выполнит проверки после установки. `.git`, история Git и файлы вне списка обновления не затрагиваются. При ошибке проверки изменённые исходники восстанавливаются из копии.

Если сервер превью запущен, остановите его в терминале через `Ctrl+C`. Загрузите `mrhilicks-site-update.zip` в корень репозитория и выполните:

```bash
tmpdir="$(mktemp -d)"
unzip -q mrhilicks-site-update.zip -d "$tmpdir"
python3 "$tmpdir/mrhilicks-site-update/apply_update.py" --target "$PWD"
python3 scripts/dev.py
```

Проверка без применения: добавьте `--dry-run` к команде установщика. Резервная копия сохраняется в домашней папке Codespaces: `~/mrhilicks-site-backups/<имя-репозитория>/<время-установки>/files/`. Точный путь напечатает установщик. Не закрывайте Codespace, не сохранив важные изменения в Git или отдельно: копия находится в этом же облачном окружении.

## Локальный просмотр

```bash
python3 scripts/dev.py
```

В Codespaces: нижняя панель **Порты → 8000 → Открыть в браузере**. Адрес английской версии — `/`, русской — `/ru/`. Обновляйте страницу после редактирования файлов. Приватность порта можно оставить прежней. Если 8000 занят, используйте `python3 scripts/dev.py --port 8001` и откройте 8001.

## Где редактировать

| `content/site.json` | Публичное имя, локализованные имена `names`, контакты, домен, версия, параметры индексации и шрифтов |
| `content/ru.json`, `content/en.json` | Описания, услуги, FAQ, данные кейсов, подписи галерей |
| `content/media.json` | Размеры веб-изображений и варианты для адаптивной загрузки |
| `assets/images/gallery/` | Полные веб-копии рисунков и уменьшенные варианты |

| `assets/css/styles.css` | Дизайн и адаптивная вёрстка |

`_site/` — результат сборки, не исходники. Его не следует править вручную или добавлять в Git. Сборщик копирует туда только веб-материалы; исходные ZIP, CSV-инвентаризация и служебные документы не публикуются.

### Добавление иллюстраций

Поместите WebP в `assets/images/`, укажите его в `gallery` нужного проекта в обеих локализациях. Поля: `file`, `alt`, `caption`; `wide: true` растягивает схему на всю ширину галереи. В `content/media.json` укажите фактические `width`, `height`, а для адаптивной загрузки — список `variants` с полями `file`, `width`. Подпись должна объяснять изображение и ограничения интерпретации. Не используйте уменьшенные веб-картинки для измерений.

Для изменения главной обложки проекта правьте `image` и `image_alt`. Рисунки первого экрана выбираются в `home_body()` в `scripts/build.py`. На сайте используется сравнение двух изображений, а не измерительный ГИС-инструмент.

### Контакты и форма

Email и Telegram уже заполнены. `mailto:` открывает почтовую программу; Telegram ведёт напрямую на профиль. Конструктор задания работает только в браузере: готовит текст и копирует его либо предлагает ручное копирование. Он не отправляет сообщения, не принимает файлы и не сохраняет введённые данные. Backend и внешняя форма не подключены.

### Языки и шрифты

Ключи EN/RU, порядок проектов, пути к изображениям и статусы должны совпадать. Встроенные подписи на картах и оригинальные PDF остаются на русском; описания, подписи под рисунками, меню и интерфейс доступны на двух языках. Фото и CV не добавлялись, поскольку материалы не предоставлены.

Файлы шрифтов не входят в проект. `use_google_fonts: true` подключает Manrope и IBM Plex Mono; при недоступности используются системные шрифты. `false` полностью отключает запросы к Google Fonts. Внешние аналитические скрипты и рекламные пиксели не добавлены.

## Проверка и сборка

```bash
python3 scripts/check.py
python3 scripts/build.py
```

Первая команда также выполняет сборку. Проверяются ссылки, PDF, изображения и варианты `srcset`, якоря, дубли ID, языки, H1/main и встроенный JSON. Дополнительная проверка обновления описана в `QA.md`.

## Публикация

Существующий workflow GitHub Pages и конфигурация Codespaces не менялись. Установщик не коммитит изменения, не пушит их и не публикует сайт. Сначала просмотрите обе версии через приватное превью, затем сохраните изменения обычным способом.

Для существующей настройки **GitHub Actions** публикуется только `_site/` после обновления основной ветки, как и раньше. Перед этим проверьте права на исходные наборы снимков и подписи источников. `indexable` намеренно оставлен `false`, как в предыдущей версии. Это запрет индексации для поисковых систем, а не защита доступа: опубликованные Pages, картинки и PDF доступны по ссылкам. После проверки содержимого и атрибуции можно изменить значение на `true`.
